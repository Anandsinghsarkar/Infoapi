# InfoAPI

Simple JSON REST API for Vercel.

## Endpoints

- `GET /api/user/1` — get a user by ID
- `GET /api/search?q=anand` — search across fields
- `GET /api/info?number=123` — find matching values

## Data

Replace `data/data.json` with your own **synthetic or properly anonymized data**. Do not publish private personal information or leaked datasets.

## Deploy

Import this repository into Vercel. No build command is required.
